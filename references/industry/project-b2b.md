# 行业插件：项目型 B2B（建材、保温材料、工程设备、工业品）

当客户是工程承包商、经销商、建材零售连锁、设计院，或者询盘里涉及具体项目、招标、技术规格、认证要求时阅读。通用流程不变，本文件补充四件事：渠道层级、项目真实性、认证核验、现有供应商追溯。核验日期：2026-10。

## 1. 先弄清楚渠道层级

建材和工业品的渠道很长：工厂 → 进口商/经销商 → 分包商或工程承包商 → 项目业主或终端用户。旁边还有设计院、顾问负责指定品牌和规格。

| 对方是谁 | 背调重点 | 付款风险 |
|---|---|---|
| 进口商/经销商 | 进口记录、仓库、分销网络、是否独家 | 中；适合 30% 定金 + 70% 见提单副本 |
| 工程承包商 | 承包资质、以往项目、本项目是否真实、业主是谁 | 承包商垫资压力大，账期诉求多；赊销前必须深调 |
| 零售连锁 | 门店数量、上市公司年报、供应商准入流程 | 大型连锁信用好，但账期长、扣款条款多 |
| 设计院/顾问 | 一般不直接付款；问清楚实际下单方 | 背调对象改为实际下单方 |
| 承包商兼经销商的混合体 | 两种角色分别核验；合同主体是哪一个 | 以合同主体为准 |

`scripts/risk_score.py` 可以使用 `"weights": "project_b2b"` 预设：诉讼和经营年限的权重更高，数字口碑的权重更低。报告中写明使用了这个预设。

## 2. 项目真实性

- 拿到项目名称、地点、业主、招标编号后，到政府采购网站核对。可用的入口有：欧盟 TED、英国 Contracts Finder、澳大利亚 AusTender、沙特 Etimad、世界银行项目采购（链接见 `../free-paths.md` 问题 7）。
- 私人项目：核对业主公司是否存在、项目所在地是否有开工迹象（地图、新闻、规划许可公告）。
- 风险信号：查不到项目；只要报价单和图纸、不谈样品；要求在极短时间内给出全套技术方案；采购量与项目规模明显不匹配。
- 防套图纸：报价只给区间；详细图纸和配方签保密协议后再提供，并在文件上加水印。

## 3. 认证核验（对方要求的、对方出示的都要查）

| 市场 | 认证或制度 | 官方查询入口 | 要点 |
|---|---|---|---|
| 澳大利亚 | CodeMark（建筑产品符合性认证） | https://codemark.abcb.gov.au/register | 查证书编号、持证人、有效期；也要确认这个项目是否确实需要 CodeMark |
| 沙特 | SABER（产品符合性证书平台，SASO） | https://saber.sa/?lang=en | 管制类产品清关需要；证书真伪以平台记录为准 |
| 欧盟 | CE 标志的公告机构（Notified Body） | https://webgate.ec.europa.eu/single-market-compliance-space/notified-bodies | 核对证书上的公告机构编号是否真实存在、是否有该产品类别的授权 |
| 全球 | ISO 等管理体系认证 | https://www.iafcertsearch.org | IAF 认可的认证证书检索；查不到时，再到发证机构官网查 |

判断"认证要求是否合理"：对方要求的认证在目的国并不强制，或项目根本用不到，可能是在拖时间或比价；对方自己出示的证书过期或查无此证，记为身份核验的风险点。

## 4. 现有供应商追溯（按 HS 编码）

- 先确定产品的 HS 编码，以报关实际使用的编码为准。保温材料常见的章节有 3921（塑料板片）和 6806（矿物棉等）。
- 美国买家：在 ImportYeti 按公司名搜索进口提单，看供应商名称、原产国、频率。
- 其他国家：用 52wmb 的免费部分，或者 UN Comtrade 看宏观进口量。
- 用途：判断对方是否真的常年进口同类产品；了解它现在的供应商，从而判断我方的切入点和价格区间。

## 5. 行业 Red Flags

- 项目查不到，只要报价和图纸。
- 自称终端用户，官网却是贸易公司；或者说不清货物最终用在哪个项目。
- 要求的认证与目的国的法规不符，或者催促"先发货，证书以后补"。
- 合同主体、付款方、收货方是三家不同的公司（三角贸易，见 `../dimensions.md` 欺诈信号表）。
