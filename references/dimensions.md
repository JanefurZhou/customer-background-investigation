# 调查维度、评分锚点与欺诈信号

深度尽调时通读；快筛只需第 1、7 节和欺诈信号表。每个维度按文末锚点打 0–10 分，查不到写 `null`（不要自己填 5，脚本会处理）。

## 1. 企业身份核验

- 全称、注册号、税号（VAT/EIN/CNPJ 等）、成立日期、类型、存续状态。
- 注册地址与经营地址是否一致；地图街景是否为真实办公室、仓库或门店。
- 董事和授权签字人与对接人是否对得上。
- 登记的经营范围与询盘品类是否匹配。
- 同名排除：至少用注册号 + 地址 + 一名董事三项中的两项确认。

## 2. 股权结构、UBO 与离岸主体

- 股东、持股比例，尽量穿透到最终受益人（英国查 PSC；欧盟各国 UBO 登记多数需要申请访问）。
- 警惕代持、多层离岸嵌套、董事为另一离岸实体。
- 离岸辖区（BVI、开曼、塞舌尔、巴拿马等）公开信息少：要求客户提供 Certificate of Incorporation、Certificate of Good Standing、Certificate of Incumbency；核对合同地址是否只是注册代理地址；同时加强制裁和不利媒体检索；付款建议至少按 🟡 处理。
- 美国特拉华等州：只能查到存续状态，股东不公开，以客户提供的文件和交易记录补充。

| 辖区 | 公开程度 | 做法 |
|---|---|---|
| BVI | 低 | 要求 Certificate of Incumbency 和 Good Standing；可付费查询公司状态；核对合同地址是否只是注册代理地址 |
| 开曼 | 低 | 要求注册证书和存续证明；受监管实体（基金、银行）可在 CIMA 查询 |
| 百慕大 | 中低 | 公司注册处可付费查询基本信息 |
| 巴拿马 | 低 | 要求公证文件；查公共登记处；留意同地址是否有受制裁实体 |
| 塞舌尔 | 低 | 同 BVI，核实注册代理人 |
| 特拉华 | 中 | 州务卿网站可查存续状态，股东不公开 |

离岸主体同时用 ICIJ 离岸泄露数据库检索（见 `free-paths.md` 问题 2）。
- 风险信号：成立很短却声称有多年经验；名称带"瑞士/伦敦集团"但注册在离岸地；拿不出存续证明。

## 3. 财务与信用

- 上市公司查年报；英国小公司在 Companies House 也有年报。
- D&B 公司目录：https://www.dnb.com/business-directory.html（只有基础信息）。
- 破产/清算公告：英国 https://www.thegazette.co.uk；其他国家查官方公报。
- 没有付费数据时，用 LinkedIn 员工数、招聘动态、门店数量、评价数量间接估计规模，并标注为"推断"。
- 国家风险参考：中国信保 https://www.sinosure.com.cn；Coface https://www.coface.com/Economic-Studies-and-Country-Risks；Allianz Trade（原裕利安宜）https://www.allianz-trade.com/en_global/economic-research/country-reports.html；Atradius https://group.atradius.com/knowledge-and-research/reports

## 4. 司法与诉讼

- 美国：https://www.courtlistener.com（免费），https://pacer.uscourts.gov（低价按页收费）。
- 英国：https://www.bailii.org；欧盟：https://e-justice.europa.eu
- 中国关联方：https://wenshu.court.gov.cn，执行信息 http://zxgk.court.gov.cn（境外 IP 可能无法访问）
- 国际投资仲裁：https://icsid.worldbank.org
- 商标/品牌：https://branddb.wipo.int，以及 USPTO、EUIPO。
- 区分：作为原告还是被告、金额、是否涉及拖欠货款或欺诈。

## 6. 经营与行业

按客户类型调整重点：

| 客户类型 | 关键验证点 |
|---|---|
| 品牌方 | 目标市场的商标注册人是否为该公司；官网与品牌一致；警惕近似品牌名 |
| 批发/分销商 | 仓库地址真实；品牌授权书；上下游合作年限 |
| 进口商/贸易商 | 海关提单记录；VAT/EORI 有效；是否频繁改名或搬家 |
| 制造商/工厂 | ISO 等认证到发证机构官网核对；卫星图看厂房规模；视频验厂或第三方验厂 |
| 零售/电商 | 店铺评分、开店时间、消费者投诉（Trustpilot、Google、BBB） |
| 代理/中间人 | 书面授权委托书；委托方真实存在；"独家代理"却无书面授权需警惕 |
| 工程承包商 | 承包资质或分级证书；以往中标或完工项目（政府采购网站可查）；项目业主是否真实存在 |
| 设计院/顾问 | 只做选型和指定品牌，一般不直接付款；问清楚实际下单方是谁，背调对象改为下单方 |
| 建材/家居零售连锁 | 门店数量和分布（地图）；上市公司查年报；采购部门的联系方式以官网为准 |
| 供应商（我方采购） | 生产资质、认证真伪（见第 6B 节）、实际工厂地址、视频验厂、报价是否明显低于行情 |
| 货代/服务商 | 行业牌照（如美国 NVOCC 可查 FMC） |

商业逻辑三问（每家都要能答出，并附证据）：
1. 它卖什么？主营品类、客群（B2B/B2C）、价位。
2. 它的公开立场是什么？比如 fur-free、vegan、可持续认证，以及目标市场的法规限制。
3. 这次询盘和前两问对得上吗？对不上（比如激光厂询皮草、fur-free 品牌要真皮草）就按冒充嫌疑处理。

名称不代表业务：名字里带 fur、leather 的不一定卖真皮，带 eco、faux 的也不一定只做替代材料。以官网产品页和公开声明为准，调研顺序为官网 → 搜索引擎 → LinkedIn → 社媒 → 行业数据库的顺序。

## 6B. 交易真实性核验（大额、项目型、首次合作必做）

查"这家公司真不真"还不够，还要查"这笔生意真不真"。

| 检查项 | 怎么查 | 风险信号 |
|---|---|---|
| 终端用户还是中间商 | 问清楚货物最后用在哪里、卖给谁；对照对方官网的业务描述 | 自称终端用户，官网却是贸易公司；说不清最终用途 |
| 项目真实性 | 项目名称、业主、地点、招标编号，到政府采购网站核对（见 `free-paths.md` 问题 7） | 查不到项目；只要报价单和技术图纸、不谈样品和付款；催得很急 |
| 采购阶段 | 判断对方处在哪一步：规格确认 → 样品测试 → 项目报价 → 招标 → 签约 | 跳过样品和规格确认，直接要求最低价和大量资料（常见于套报价、套图纸） |
| 现有供应商 | 美国买家用 ImportYeti 查进口提单，看它现在从哪里、向谁采购；其他国家用 52wmb 的免费部分 | 自称常年进口同类产品，却没有任何进口记录 |
| 认证要求 | 对方声称需要的认证，到发证机构的官方登记里核对是否真实、是否过期（见 `industry/project-b2b.md`） | 要求的认证在目的国并不强制；或对方自己出示的证书已经过期 |
| 需求匹配 | 询盘品类分别对照我方能力、对方主营、对方历史进口品类（见 `inquiry-checks.md` 第 4 节） | 要的东西我们不做（成品 vs 原料）；历史上从未进口同类 → 新品类开发，先澄清再报价 |
| 进口量化 | 进口提单导出 CSV，运行 `scripts/customs_summary.py`，看票数、月均 TEU、规模分档、进口中断（第 6 节） | 自称大买家，月均却不足 0.5 TEU；最近一票距今超过采购间隔的 2 倍且超过 180 天 |
| 询盘文本特征 | 是否模板化、是否提到我方任何产品或网站内容 | 群发式询盘：不算风险，只调低转化预期，结论里单独写一句 |

以上结论计入评分：业务对不上计入"企业身份"或"数字口碑"维度；确认是套报价或冒充的，按 `fraud_confirmed` 处理。

## 7. 数字化存在与一致性（快筛必做）

- 运行 `python3 scripts/domain_check.py --sender <对方邮箱> --official <官方域名> [--claimed-since <年份>]`，把输出的 level 和 signals 写进报告。脚本以形似度、域名年龄、免费邮箱为主要依据；MX 有效只说明能收信，仿冒域名通常也有 MX，不能作为"真实"的证据。
- 自称大公司却用免费邮箱的，需要追问。
- 域名注册时间（https://lookup.icann.org；.com/.net 可直接查 `https://rdap.verisign.com/com/v1/domain/<域名>`）与最早网页存档（`https://archive.org/wayback/available?url=<域名>&timestamp=19900101`）是否与声称的经营年限相符。风险信号是"新域名配老公司"；域名比公司还老通常是收购来的旧域名，不算风险，但要写明"推断"。
- 官网的电话、地址是否与登记信息一致。
- 收款/付款账户名是否与合同主体一致；账户所在国是否与公司所在国相符。
- 是否存在仿冒网站或相似域名；社媒是否长期有真实更新。官方社媒停更超过 12 个月，而对方自称业务正常扩张，写进风险信号并追问（单独出现不加分）。
- 发件人与电话、邮件头与 DMARC、邮箱命名规则的核验方法见 `inquiry-checks.md` 第 1–3 节。

## 8. 贸易与物流

- 免费贸易数据：ImportYeti https://www.importyeti.com（美国进口提单），52wmb https://www.52wmb.com（部分免费），UN Comtrade https://comtradeplus.un.org（只有宏观数据）。
- 目的国关税、配额、反倾销、外汇管制；所售品类是否受准入限制（见 `industry/`）。
- 进口中断（`customs_summary.py` 报出）：可能是换了供应商、经营收缩或改从第三国进口，追问原因；同时出现财务或诉讼负面时，"经营稳定性"维度上调。

## 欺诈信号

| 类型 | 表现 | 核验 |
|---|---|---|
| 预付款/费用诈骗 | 要求卖方先付"注册费、认证费、律师费" | 正规买家不会向卖方收费；直接判为欺诈信号 |
| 冒充知名买家 | 用免费邮箱或近似域名，自称大品牌采购 | 对比品牌官网的域名和联系方式 |
| 空壳公司 | 虚拟办公室、无员工、官网无内容 | 地图街景；LinkedIn 员工；电话核验 |
| 过度订购 | 小额首单正常付款，紧接着大额赊销后失联 | 第二单仍坚持安全付款方式 |
| 账户变更 | 邮件通知更换收/付款账户 | 用已知电话二次确认，不用邮件里留的号码 |
| 套报价、套图纸 | 编造的项目，只要报价、技术方案、图纸，不谈样品和付款 | 核对项目真实性（第 6B 节）；报价只给区间，详细图纸签保密协议后再给 |
| 三角贸易、第三方付款 | 付款人、收货人、合同主体是三家不同的公司，或者从第三国付款 | 要求合同主体付款；第三方付款必须说明理由并核验付款方；留意转运风险（见 `screening.md`） |
| 单据造假 | 伪造提单、信用证 | 在船公司官网追踪柜号；核实开证行 |

只有"已确认"的欺诈信号才设 `fraud_confirmed: true`；单个疑点只提高相关维度分数。

## 评分锚点（0 = 无风险，10 = 极高）

| 维度 | 0 | 3 | 5 | 8 | 10 |
|---|---|---|---|---|---|
| sanctions 制裁与合规 | 全部未命中 | 有轻微不利新闻 | 有疑似同名且已排除，或高风险辖区 | 有严重不利媒体，或 PEP 关联 | 名单命中（同时设否决项） |
| litigation 司法诉讼 | 无记录 | 零星小额纠纷 | 多起商业诉讼 | 涉及拖欠货款的诉讼或判决 | 欺诈判决或破产 |
| identity 企业身份 | 全部核验一致 | 有轻微出入且可解释 | 部分信息无法核验 | 关键信息矛盾 | 查无此公司或证件虚假（同时设否决项） |
| financial 财务信用 | 财务稳健/评级好 | 中等规模，无负面 | 无数据，靠推断 | 亏损、延迟申报年报 | 破产清算或严重违约 |
| stability 经营稳定性 | 10 年以上且稳定 | 5–10 年 | 3–5 年，或近期频繁变更 | 1–3 年 | 不足 1 年，或已停业 |
| digital 数字口碑 | 信息丰富、口碑好 | 信息较少，无负面 | 邮箱或域名有轻微不一致 | 大量负面评价，或新域名配老品牌 | 仿冒网站，或冒用他人身份 |
| trade 贸易物流 | 贸易记录正常，低风险国 | 有少量风险因素 | 中风险国，或外汇管制 | 高风险国 | 禁运国或受全面制裁地区 |

## 常见误区

| 误区 | 正确做法 |
|---|---|
| 登记处搜不到就是骗子 | 离岸辖区、个体经营者可能本来就查不到；标注信息缺口，请对方自证 |
| 域名能收信就是真的 | 仿冒域名一样能收信；看形似度和注册时间，并用官方电话回拨 |
| 域名比公司老就可疑 | 通常是收购来的旧域名；可疑的是新域名配老公司 |
| 制裁库没查到就安全 | 名单每周都在更新；写明筛查日期，签约前复查 |
| 找到一个姓名相近的人就算核验 | 拼写不同、行业不符时不能认定是同一人，也不要把这个人的私人信息写进报告 |
| 个人买家查不到网络痕迹就高风险 | 普通人本来就未必有公开足迹；个人买家只看交易安全（见 `free-paths.md`） |
| 每次换一套评分权重 | 只用 `scripts/risk_score.py`，不另造模型，也不做"映射调整" |
| 域名能对上就是本人发的 | DMARC 为 p=none 或未设置时仍可伪造；要看邮件头，或回拨总机确认 |
| 回拨对方信里留的号码 | 对方自己给的号码不能证明他自己；回拨第三方来源确认过的总机 |
| 公司老牌、规模大就可以放宽付款 | 公司真不等于这笔询盘真、也不等于是大单；按规模分档定首单，合同抬头写法定实体 |
| 群发式询盘就是骗局 | 群发只说明对方在比价，转化率低；不加风险分 |
